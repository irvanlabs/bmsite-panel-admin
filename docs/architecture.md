# Architecture

Layered architecture for **bmsite-panel**, a Nuxt 4 application (app source under `app/`). Built on the `nuxt-shadcn-dashboard` starter, extended with an Editor surface and a Phase 2 design-token system.

---

## Layers

```
nuxt-shadcn-dashboard (base starter)
        │
        ├─ app base (layouts, ui primitives, design tokens)
        │
        ├─ client / admin / auth / blank  →  route layouts
        │
        └─ pages (client/*, admin/*, auth/*)  →  compose component buckets
                    │
                    ├─ shared/*     reusable cross-page primitives
                    ├─ dashboard/*  client dashboard compositions
                    ├─ editor/*     website editor compositions
                    └─ layout/*     chrome (sidebar, header, nav)
```

---

## 1. App base

- **Design tokens** — single source of truth in `app/assets/css/tailwind.css` (base `:root` + `.dark` overrides) and `app/assets/css/themes.css` (imported). Exposed to Tailwind via `@theme inline` (`app/assets/css/tailwind.css:8`).
- **UI primitives** — `app/components/ui/*` (shadcn-vue, auto-generated). Never edited by hand; regenerated by the shadcn CLI.
- **Core composables** — `app/composables/` (`useAppSettings`, `useShortcuts`, `useKanban`, `defineShortcuts`) and `app/composables/shared/` (`useSidebarSession`).
- **Services / types / config** — see folders below.

---

## 2. Layouts (route shells)

`app/layouts/`:

| Layout | File | Purpose |
|---|---|---|
| `client` | `client.vue` | Sidebar + `DashboardHeader` + content inset (`p-4 lg:p-6`). Used by dashboard + editor pages. |
| `admin` | `admin.vue` | Admin shell. |
| `auth` | `auth.vue` | Centered auth shell. |
| `blank` | `blank.vue` | Bare shell (no chrome). |

Each page opts into a layout via `definePageMeta({ layout })`. The client dashboard and the website editor both use `layout: 'client'`.

---

## 3. Component buckets

| Bucket | Path | Scope |
|---|---|---|
| `shared` | `app/components/shared/` | Cross-page building blocks (headers, cards, badges, dialogs, form fields, timeline, uploader). |
| `dashboard` | `app/components/dashboard/` | Client dashboard cards; compose shared primitives with dashboard tokens. |
| `editor` | `app/components/editor/` | Website editor surfaces; use `editor-*` tokens. |
| `layout` | `app/components/layout/` | Chrome: `ClientSidebar`, `AdminSidebar`, `DashboardHeader`, `Header`, `TopNavigation`, `ContentWrapper`, `PageContainer`, `BaseSidebar`, `SidebarNav*`. |
| `base` | `app/components/base/` | `BreadcrumbCustom`, `DateRangePicker`. |
| `ui` | `app/components/ui/` | shadcn-vue primitives (generated). |

---

## 4. Config-driven navigation

`app/config/navigation/`:

- `client.ts` — `clientNav` (`NavMenu[]`: Overview + Account headings) and `clientNavBottom` (`NavLink[]`: Help & Support, Feedback). Icons are `i-lucide-*` strings.
- `admin.ts` — admin nav config (same shape).

Types in `app/types/nav.d.ts` (`NavMenu`, `NavLink`). The sidebar renders from this config — **add a menu entry here, not in the component**, to surface a new route.

---

## 5. Services / Composables / Types

- `app/services/` — API/data-access layer (per-domain service modules).
- `app/composables/` — stateful logic (`useSidebarSession`, `useAppSettings`, shortcuts, kanban).
- `app/types/` — shared domain types:
  - `shared/index.ts` — `UserProfile`, `ActivityItem`, `SubscriptionInfo`, `WebsiteInfo`.
  - `client/index.ts` — `EditorFormData`, `PreviewData`.
  - `nav.d.ts`, `appSettings.d.ts`, `kanban.ts`.

---

## 6. Design tokens location

All tokens: `app/assets/css/tailwind.css` (`:root` + `.dark`) and `app/assets/css/themes.css`. Mapped into Tailwind's theme at `app/assets/css/tailwind.css:8` (`@theme inline`). Two coordinated systems:

- **Base/shadcn** — neutral (`--background`, `--primary`, `--muted`, `--ring`, `--radius-*`).
- **Editor** — `editor-*` blue palette + `editor-radius-*` / `editor-*-spacing` tokens. Brand blue `editor-primary` (`#0F6AAE`) is the shared single source.

---

## 7. How a future page plugs in

1. **Add the route.** Create the file:
   - Client page → `app/pages/client/<name>.vue` (or nested `app/pages/client/<group>/<name>.vue`).
   - Admin page → `app/pages/admin/<name>.vue`.
2. **Declare the layout:**
   ```ts
   definePageMeta({ layout: 'client' }) // or 'admin' / 'auth' / 'blank'
   ```
3. **Surface it in nav.** Add an entry to `app/config/navigation/client.ts` (or `admin.ts`):
   ```ts
   { title: 'My Page', icon: 'i-lucide-sparkles', link: '/client/my-page' }
   ```
4. **Compose from buckets.** Use `shared/*` primitives first; add `dashboard/*` or `editor/*` only if page-specific. Reference brand color via `editor-primary` — do not hardcode blue.
5. **Follow conventions.** `PageHeader`/`SectionHeader` for titles, `rounded-2xl` for shared cards, `rounded-xl` for shared buttons, `text-xs uppercase tracking-widest text-muted-foreground` for labels, `focus-visible:ring-2 ring-ring` for focus.

No registration with a router module is needed — Nuxt file-based routing picks up `app/pages/**` automatically.
